# Beginner Trading Toolkit

An organized, self-contained starting point for learning to trade properly:
chart reading, strategy design, risk management, and the tools to apply it
(position sizing, trade journal, backtesting) — no paid course, no signals
service, no external dependencies required (pure Python 3 standard library).

**No installation needed** — everything runs with plain `python3`, no `pip install` required.

## Start here: `learn/study_plan.md`

That file is the actual organized 8-week plan. Follow it in order:

```
learn/
  01_chart_reading.md      <- Week 1-2: how to read candles, trend, S/R, indicators
  02_strategy_basics.md    <- Week 3: what a real strategy is, 3 beginner archetypes
  03_risk_management.md    <- read alongside Week 3+: position sizing, drawdown limits
  study_plan.md             <- the week-by-week checklist that ties it all together
```

## Tools (`tools/`)

| Tool | Purpose | Example |
|---|---|---|
| `position_sizing.py` | Calculates exact position size from account balance, risk %, entry, and stop -- use before every trade | `python3 tools/position_sizing.py --balance 2000 --risk-pct 1 --entry 50 --stop 48` |
| `trade_journal_template.csv` | Log every trade (demo or real) here. Open in Excel/Google Sheets/Numbers. | Duplicate the header row for each new trade |
| `backtest.py` | Dependency-free EMA-crossover backtester to test a rule set against historical data | `python3 tools/backtest.py --data sample_data/sample_ohlcv.csv` |
| `generate_sample_data.py` | Generates synthetic OHLCV data to practice with `backtest.py` before you have real data | `python3 tools/generate_sample_data.py --out ../sample_data/sample_ohlcv.csv` |

### Quick start
```bash
# 1. Try the position sizing calculator (interactive mode, no flags needed)
python3 tools/position_sizing.py

# 2. Run the sample backtest to see the mechanics
python3 tools/backtest.py --data sample_data/sample_ohlcv.csv --risk-pct 1

# 3. Start logging trades
#    Open tools/trade_journal_template.csv, duplicate the example row per trade
```

**Important:** `sample_data/sample_ohlcv.csv` is synthetic/fake data generated by
`generate_sample_data.py` — it exists only so you can practice running the
backtester. Replace it with real historical data (exported from your
broker/data provider as `Date,Open,High,Low,Close,Volume` CSV) before drawing
any real conclusions about a strategy.

## The one rule that matters more than any of this

Risk 1-2% of your account per trade, max. Never size a position at 100% of
your account — see `learn/03_risk_management.md` for exactly why (it's math,
not opinion: a single full-size loss ends the account; a properly-sized loss
lets you take the next 50-100 trades).
